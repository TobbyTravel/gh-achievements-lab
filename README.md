# gh-achievements-lab

This is a small, dedicated **test repository** used to legitimately unlock a
few [GitHub profile achievements](https://github.com/TobbyTravel?tab=achievements)
through normal GitHub workflows (opening/merging PRs, closing issues quickly,
answering a Discussions question). It contains no real project code.

All activity here is clearly labeled as achievement/test activity and does not
represent production work.
